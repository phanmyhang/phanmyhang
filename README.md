## 🚀 Chạy thử ở máy (cho dev)

```bash
npm install     # warm-up: cài dependencies
npm run dev     # vào set: localhost:4321
npm run build   # finish: xuất trang tĩnh ra ./dist
```

Mỗi lần push lên `main`, trang **tự động build & lên sóng** qua GitHub Actions — như một buổi tập đúng lịch, không bỏ buổi nào. 💯
